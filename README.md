# Document-Expiration-Alert

ตัวแจ้งเตือนเอกสารพนักงานต่างชาติใกล้หมดอายุ: **Work Permit**, **Passport** และ **Visa**
แจ้งเตือนล่วงหน้า 90 วัน (ปรับจำนวนวันได้)

## วิธีใช้
1. เปิด `index.html` ในเบราว์เซอร์ (หรือเปิดผ่าน GitHub Pages)
2. กด **อัปโหลดไฟล์ Excel** หรือลากไฟล์ `.xlsx / .xls / .csv` มาวางที่หน้าเว็บ
3. ระบบแสดงรายการแยกตาม Work Permit / Passport / Visa เรียงจากใกล้หมดอายุที่สุด
4. มีไฟล์อัปเดตเมื่อไรก็อัปโหลดไฟล์ใหม่ได้เลย รายการจะคำนวณใหม่ทันที

## คอลัมน์ที่ระบบอ่านจากไฟล์
| ข้อมูลที่แสดง | วันหมดอายุที่ตรวจ |
|---|---|
| PeopleSoft ID, คำนำหน้าชื่อ (อังกฤษ), ชื่อ (ไทย), หน่วยงานปัจจุบัน, เลขที่หนังสือเดินทาง, เลขประจำตัวคนต่างด้าว, ใบอนุญาตทำงานเลขที่ | Work Permit หมดอายุ, Passport หมดอายุ, Visa หมดอายุ |

- ระบบหาแถวหัวตารางที่มีคำว่า "PeopleSoft ID" เอง ไม่ต้องอยู่แถวแรก และหัวตารางขึ้นบรรทัดใหม่ในเซลล์ได้
- รองรับวันที่แบบ Excel, `dd/mm/yyyy`, ปี พ.ศ. และชื่อเดือนไทย เช่น `3 ม.ค. 2570`

## สถานะ
- 🔴 หมดอายุแล้ว · 🟠 ≤ 30 วัน (ด่วน) · 🟡 31–60 วัน · 🔵 61–90 วัน
