# ตั้งค่าแจ้งเตือนเอกสารหมดอายุผ่าน LINE

ระบบจะอ่านข้อมูลจาก Google Sheet ทุกเช้า แล้วส่งรายชื่อพนักงานที่ Work Permit / Passport / Visa
จะหมดอายุภายใน 90 วัน (รวมที่หมดอายุแล้ว) เข้า LINE

ใช้เวลาตั้งค่าประมาณ 20–30 นาที ทำครั้งเดียว

---

## ส่วนที่ 1: Google Sheet

1. เปิด https://sheets.new (สร้าง Google Sheet ใหม่) ตั้งชื่อเช่น `AEC ศาลายา เอกสารหมดอายุ`
2. **ไฟล์ → นำเข้า → อัปโหลด** เลือกไฟล์ `68 ศาลายา_รายชื่อ AEC และวันที่หมดอายุของเอกสาร.xlsx`
   แล้วเลือก **แทนที่สเปรดชีต** → **นำเข้าข้อมูล**
3. **ไฟล์ → การตั้งค่า → เขตเวลา** เลือก `(GMT+07:00) Bangkok` → บันทึก
4. **ส่วนขยาย → Apps Script**
   - ลบโค้ดเดิมในไฟล์ `Code.gs` ให้หมด แล้ววางโค้ดทั้งหมดจาก [Code.gs](Code.gs) (กดปุ่ม Copy raw file มุมขวาบน)
   - กดไอคอนบันทึก (💾) ตั้งชื่อโปรเจกต์เช่น `LINE Alert`
5. กลับมาที่ Google Sheet แล้ว **รีเฟรชหน้า** จะมีเมนู **แจ้งเตือน LINE** ขึ้นด้านบน
6. กด **แจ้งเตือน LINE → ดูตัวอย่างข้อความ (ยังไม่ส่ง)**
   - ครั้งแรก Google จะขอสิทธิ์ → เลือกบัญชีของคุณ
   - ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง → ไปที่ LINE Alert (ไม่ปลอดภัย)** → **อนุญาต**
     (ขึ้นเพราะเป็นสคริปต์ที่คุณสร้างเอง ไม่ได้ส่งให้ Google ตรวจ)
   - จะเห็นข้อความตัวอย่างที่จะส่งเข้า LINE โดยยังไม่ได้ส่งจริง

> อย่าแชร์ Google Sheet นี้ให้คนนอก เพราะมีข้อมูลส่วนตัวของพนักงาน

---

## ส่วนที่ 2: LINE Official Account (บอทที่ส่งข้อความ)

1. เข้า https://manager.line.biz → **สร้างบัญชี LINE Official Account** (ฟรี)
   กรอกชื่อบัญชีเช่น `HR แจ้งเตือนเอกสาร`
2. ในหน้าจัดการบัญชี: **ตั้งค่า (Settings) → Messaging API → ใช้ Messaging API**
   → สร้างหรือเลือก Provider → ยืนยัน
3. เข้า https://developers.line.biz/console → เลือก Provider → เลือก Channel ของบัญชีที่สร้าง
   → แท็บ **Messaging API** → เลื่อนลงไปที่ **Channel access token (long-lived)** → กด **Issue** → คัดลอก
4. กลับไปที่ Google Sheet: **แจ้งเตือน LINE → ตั้งค่า LINE token** → วาง token → OK
   (token เก็บในสคริปต์ คนที่เปิดชีตจะไม่เห็น อย่าส่ง token ให้ใครหรือวางไว้ในชีต)
5. ให้ทุกคนที่ต้องได้รับแจ้งเตือน **แอดบอทเป็นเพื่อน** โดยสแกน QR code ในแท็บ Messaging API
6. ทดสอบ: **แจ้งเตือน LINE → ส่งแจ้งเตือนตอนนี้** ข้อความจะเข้า LINE ของทุกคนที่แอดบอท
7. ตั้งส่งอัตโนมัติ: **แจ้งเตือน LINE → ตั้งให้ส่งอัตโนมัติทุกวัน** (หรือ **ทุกวันจันทร์**)
   จะส่งช่วง 8:00–9:00 น. ซึ่ง Google กำหนดเป็นช่วงเวลา ไม่ได้ตรงนาทีเป๊ะ

ถึงตรงนี้ใช้งานได้แล้ว ส่วนที่ 3 ทำเฉพาะถ้าต้องการให้ส่งเข้า **กลุ่ม LINE**

---

## ส่วนที่ 3 (ไม่บังคับ): ส่งเข้ากลุ่ม LINE

1. ที่ https://manager.line.biz → **ตั้งค่า → ตั้งค่าบัญชี** → เปิด **อนุญาตให้บัญชีเข้าร่วมแชทกลุ่ม**
   และที่ **ตั้งค่าการตอบกลับ** → เปิด **Webhook**
2. ที่ Apps Script: **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
3. ที่ LINE Developers → แท็บ Messaging API → **Webhook URL** → วาง URL → Update
   → เปิด **Use webhook**
   (ถ้ากด Verify แล้วขึ้น error ไม่เป็นไร เกิดจาก Google ส่งต่อลิงก์ แต่ระบบยังทำงานได้)
4. เชิญบอทเข้ากลุ่ม LINE ที่ต้องการ
5. ที่ Google Sheet: **แจ้งเตือน LINE → ส่งเข้ากลุ่ม LINE: ขอรหัสลงทะเบียนกลุ่ม** จะได้รหัส 6 หลัก
6. พิมพ์ในกลุ่ม LINE: `ลงทะเบียน 123456` (ใช้รหัสที่ได้) บอทจะตอบว่า "ลงทะเบียนแล้ว"
7. จากนี้ข้อความจะส่งเข้ากลุ่มนี้แทน ถ้าจะกลับไปส่งหาทุกคนที่แอดบอท ใช้เมนู
   **ส่งหาทุกคนที่แอดบอท (ยกเลิกการส่งเข้ากลุ่ม)**

## อัปเดตข้อมูลเมื่อมีไฟล์ Excel ใหม่

1. เปิด Google Sheet → คลิกแท็บชีต `DATA`
2. **ไฟล์ → นำเข้า → อัปโหลด** เลือกไฟล์ใหม่ → เลือก **แทนที่ชีตปัจจุบัน** → นำเข้าข้อมูล
3. เสร็จแล้ว รอบส่งถัดไปจะใช้ข้อมูลใหม่ (กด "ดูตัวอย่างข้อความ" เพื่อเช็กได้)

ชื่อหัวคอลัมน์ต้องเหมือนเดิม (PeopleSoft ID, Work Permit หมดอายุ, Passport หมดอายุ, Visa หมดอายุ ฯลฯ)
ตำแหน่งคอลัมน์หรือแถวหัวตารางเปลี่ยนได้ ระบบหาให้เอง

---

## ปรับการตั้งค่า

แก้ที่ส่วน `CONFIG` ด้านบนของ `Code.gs` แล้วกดบันทึก

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DAYS_AHEAD` | `90` | แจ้งล่วงหน้ากี่วัน |
| `INCLUDE_EXPIRED` | `true` | รวมเอกสารที่หมดอายุแล้ว |
| `INCLUDE_DOC_NUMBERS` | `false` | `true` = ส่งเลขหนังสือเดินทาง / เลขคนต่างด้าว / เลขใบอนุญาตทำงานใน LINE ด้วย |
| `SKIP_IF_EMPTY` | `true` | วันที่ไม่มีรายการจะไม่ส่ง |
| `SEND_HOUR` | `8` | ชั่วโมงที่ส่ง (เปลี่ยนแล้วต้องกดเมนูตั้งส่งอัตโนมัติใหม่) |

**เรื่องเลขเอกสาร:** ค่าเริ่มต้นไม่ส่งเลขเอกสาร เพราะข้อความใน LINE จะค้างอยู่ในมือถือทุกคนในกลุ่ม
(ข้อมูลส่วนบุคคลตาม PDPA) ถ้าบริษัทอนุญาต เปลี่ยนเป็น `true` ได้

## โควตาข้อความ LINE

- แพ็กเกจฟรีส่งได้ประมาณ 300 ข้อความต่อเดือน นับตาม **จำนวนคนที่ได้รับ**
  เช่น ส่งเข้ากลุ่มที่มี 5 คน วันละครั้ง ประมาณ 150 ข้อความต่อเดือน
- ถ้าคนเยอะหรือส่งไม่ทันโควตา ให้เปลี่ยนเป็น **ส่งทุกวันจันทร์**
- ถ้าเกินโควตา Google จะส่งอีเมลแจ้ง error มาที่บัญชีของคุณ

## ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีเมนู "แจ้งเตือน LINE" | รีเฟรชหน้า Google Sheet |
| "ไม่พบคอลัมน์ PeopleSoft ID" | ตรวจว่านำเข้าไฟล์ถูก และหัวคอลัมน์ไม่ถูกเปลี่ยนชื่อ |
| "LINE ตอบกลับ 401" | token ผิดหรือถูกออกใหม่ ตั้งค่า token อีกครั้ง |
| "LINE ตอบกลับ 429" | ส่งเกินโควตาของเดือนนี้ |
| พิมพ์ลงทะเบียนในกลุ่มแล้วบอทไม่ตอบ | เช็กส่วนที่ 3 ข้อ 1–3 และขอรหัสใหม่ (รหัสใช้ได้ครั้งเดียว) |
| แก้โค้ดแล้วกลุ่มไม่ทำงาน | ถ้าแก้ Code.gs หลัง Deploy ให้ Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่ |
